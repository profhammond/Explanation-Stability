# Results

This directory should contain only regenerated manuscript tables, figures, and compact numerical summaries. Every result must be traceable to a validated evidence file and a versioned script or notebook.

Recommended naming:

```text
results/tables/table_primary_associations.csv
results/tables/table_negative_controls.csv
results/tables/table_ph2_associations.csv
results/tables/table_protocol_sensitivity.csv
results/figures/figure_stability_quality_associations.png
results/figures/figure_cross_cohort_forest.png
```
